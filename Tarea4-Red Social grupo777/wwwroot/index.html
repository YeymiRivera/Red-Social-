Red Social 777

Proyecto académico de demostración de autenticación y publicaciones.

Esta aplicación está desarrollada con ASP.NET Core (.NET) y utiliza PostgreSQL como base de datos. Sirve para probar, en un entorno controlado, el inicio de sesión con proveedores externos y la gestión de contenido.

Qué permite hacer

  • Iniciar sesión con proveedores externos habilitados: Google, GitHub, Discord, Slack, X y TikTok.
  • Crear y editar publicaciones.
  • Organizar el contenido con categorías y etiquetas.
  • Asociar imágenes a las publicaciones.

Sobre la autenticación

La aplicación no solicita contraseñas de los proveedores. Cada proveedor devuelve un identificador de cuenta y, según el permiso autorizado, el nombre visible y el correo electrónico. Con TikTok se solicita únicamente user.info.basic, que entrega open_id y display_name; no entrega correo.
